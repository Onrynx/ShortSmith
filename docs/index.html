Shortsmith

A YouTube Shorts factory that runs on your own computer. Nothing is uploaded, nothing is tracked, and there is no account to make.

Loading the downloads…

Then two more things, once

  1. Unzip it anywhere you like — your Desktop is fine — and double-click Shortsmith.
  2. Install Ollama from ollama.com/download. That is the engine that writes the stories, and it installs itself like any normal app. Shortsmith starts it when you open it and stops it when you close it.
There is no Python to install and nothing to type. The download carries its own copy of everything it needs. Inside the app, you pick which writer model to download — it checks your memory and free disk first, and only ever fetches the one you chose.

On a Mac, one extra click the first time

Apple charges $99 a year to sign software. Shortsmith is free and is not signed, so the first time you open it macOS asks you to confirm. You do this once, ever.

  1. Download the Mac version above and unzip it.
  2. Double-click Shortsmith.command. macOS refuses it and shows a box. Click Done.
    Do not click “Move to Trash” — it is the highlighted button, so do not simply press Return. It deletes Shortsmith.
  3. Open Apple menu › System Settings › Privacy & Security, scroll to the bottom, and click Open Anyway next to Shortsmith. Enter your password.
  4. That is it. Shortsmith opens, and nothing asks you again.

The Open Anyway button only stays for about an hour after the refusal, so do step 3 straight after step 2. If it is not there, double-click Shortsmith again and look once more.

Or skip the approval entirely

If you would rather not see the box at all, this fetches the same download without the marker that triggers it, and picks Apple Silicon or Intel for you. Paste it into Terminal (press Command and Space, type Terminal, press enter): 

F=$( [ "$(uname -m)" = arm64 ] && echo Shortsmith-macOS.zip || echo Shortsmith-macOS-Intel.zip ); curl -fL -o ~/Downloads/Shortsmith.zip "https://github.com/Onrynx/ShortSmith/releases/latest/download/$F" && unzip -qo ~/Downloads/Shortsmith.zip -d ~/Desktop && open ~/Desktop/Shortsmith

Shortsmith lands on your Desktop and the folder opens. Double-click Shortsmith.command and it starts, with nothing to approve.

If Linux will not run it on a double-click

Most Linux file managers refuse to run a script until you allow it. Double-click Shortsmith.sh and choose Run if asked. If it opens in a text editor instead, right-click it, open Properties, and tick the option that allows running it as a program. Or open a terminal in the folder and type ./Shortsmith.sh.

What it does

Writes the storyGive it an idea, or nothing at all. It plans the shape, writes to it, and fits the length you asked for.
Narrates and cutsA local voice, your own gameplay clips behind it, and captions taken from the script so they are always spelled right.
Waits for youRead the script before it renders, or let it run and review the finished video. Nothing is ever published for you.
Stays on your machineNo account, no API key, no telemetry. The only things it fetches are the model you pick and its own updates.

What it needs

Windows, macOS or Linux64-bit. Apple Silicon works well.
8 GB of memory16 GB or a graphics card gets you the better writer models.
About 10 GB freeFor the app and one writer model. The app tells you what fits before you download anything.
