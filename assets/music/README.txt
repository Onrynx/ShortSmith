OPTIONAL background music — drop copyright-free tracks in here.

StoryForge picks one track per video, matched to the story's mood. Put files into
the mood subfolders (they are created automatically the first time), e.g.:

  assets/music/mystery/    assets/music/epic/    assets/music/dark/
  assets/music/adventure/  assets/music/chill/

Formats: .mp3  .wav  .m4a  .ogg
Free sources: YouTube Audio Library (studio.youtube.com), NCS, Pixabay Music.

If this folder is empty, StoryForge generates its own soft background music
automatically — you do NOT need to add anything here.
